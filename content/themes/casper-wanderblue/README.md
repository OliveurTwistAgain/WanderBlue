# Thème "casper-wanderblue"

Thème Ghost personnalisé basé sur Casper, minimaliste, pensé pour les idées de voyages.

# Installation

Copier le dossier casper-wanderblue dans content/themes/ de votre installation Ghost.

Uploader le thème depuis l’interface d’administration Ghost (General Settings → Themes → Change theme).

# Fonctionnalités

Carte leaflet dynamique sur la page d’accueil pour rechercher des lieux à visiter.

Saisie de ville, recherche de lieux et affichage des points les plus proches selon leurs coordonnées GPS.

Calcul des distances avec la formule de Haversine.

Utilisation de l’API publique Ghost pour charger les lieux et leurs coordonnées via Code Injection (Post header {{ghost_head}}
et Post footer {{ghost_foot}}).

Mise en page responsive du flux et des pages.

Gestion automatique des crédits Unsplash ou affichage du texte alternatif des images (alt).
